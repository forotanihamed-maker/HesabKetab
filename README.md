# حساب‌کتاب

یک برنامه فارسی و واکنش‌گرا برای ثبت اشخاص، مدیریت طلب‌ها و بدهی‌ها و پیگیری پرداخت‌ها.

## اجرا

```bash
npm install
npm run dev
```

برای ساخت نسخه انتشار: `npm run build`

## امکانات فعلی

- ثبت اشخاص و جلوگیری از ثبت نام تکراری
- ثبت طلب یا بدهی مستقل برای هر شخص، همراه با عنوان و دلیل
- ثبت پرداخت مرحله‌ای و محاسبه خودکار مانده
- نمایش جداگانه مجموع طلب‌ها و بدهی‌ها
- ویرایش و حذف حساب و پرداخت
- تسویه دستی پس از صفر شدن مانده
- تاریخچه فعالیت‌ها
- ذخیره اطلاعات در `localStorage` مرورگر

## ساختار پروژه

```text
src/
├── components/  # اجزای مشترک و اجزای هر بخش
├── constants/   # ثابت‌های برنامه
├── hooks/       # منطق state و عملیات حساب‌ها
├── pages/       # صفحات برنامه
├── services/    # ذخیره‌سازی داده
├── App.jsx      # اتصال صفحات و مدیریت وضعیت رابط
└── main.jsx
```

`App.jsx` فقط صفحات و وضعیت رابط را به هم متصل می‌کند. فرم‌ها، کارت‌ها، صفحات و منطق دفتر حساب در فایل‌های جدا قرار دارند.

## نکته ذخیره‌سازی

اطلاعات فعلاً فقط در مرورگر و دستگاهی ذخیره می‌شود که برنامه در آن استفاده شده است. پاک‌کردن داده‌های مرورگر ممکن است اطلاعات را از بین ببرد. همگام‌سازی بین دستگاه‌ها و پشتیبان‌گیری ابری در این نسخه وجود ندارد.
